- OS: macOS (Darwin 25.5.0)

- Textual version: 8.2.8
- Clew version: 2.0.0

## Bug 1: CSS Incompatibility with Textual 8.x — FIXED

**Severity**: Critical (blocked startup)
**Files**: `clew_tui/styles_dark.tcss`, `clew_tui/styles_light.tcss`, `clew_tui/widgets/command_palette.py`

**Root cause**: Stylesheets used CSS features unsupported in Textual 8.x:
1. CSS custom properties (`--background`, `--foreground`, `--surface`, `--primary`, `--muted`, `--border`, `--highlight`) 
2. `@keyframes` animations
3. `transition:` property with time + easing function (Textual 8.x parses `0.3s ease` differently)
4. `$panel` built-in variable in `command_palette.py` (unrecognized)

**Fix applied**:
- Replaced all `var(--*)` references with hardcoded color values in both `.tcss` files
- Removed `@keyframes fadeIn` and `@keyframes slideUp` blocks
- Removed all `transition:` properties
- Replaced `$panel` with `#161b22` in command_palette.py CSS
- Kept `$accent` and `$text` and `$text-muted` in command_palette.py (built-in Textual variables)

## Bug 2: Duplicate Screen Blocks

**Severity**: Low (visual, not blocking)
**Location**: `styles_dark.tcss:4-14`, `styles_light.tcss:4-14`

**Description**: Both stylesheets define two `Screen {}` blocks — one for base values, one with a transition that was removed. Only the second block remains effective; the first is overwritten.

**Fix applied**: Removed duplicate block; kept single Screen definition.
