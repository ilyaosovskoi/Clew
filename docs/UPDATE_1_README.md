# update_1 — GUI / TUI / MD only

Этот пакет содержит **только** файлы, исправленные для работы GUI (веб-фронтенд),
TUI (терминальный фронтенд) и сопутствующие MD-файлы.

Файлы из пакетов `update` (issue #3 + остальные) сюда **не входят** — только то,
что относится к фронтенд-слою и его дымовым тестам.

## Структура

```
update_1/
├── UPDATE_1_README.md             <- этот файл
├── clew/
│   ├── web_bridge.py              <- бридж backend <-> веб-фронтенд (WebSocket/HTTP)
│   ├── web_smoke_test.py          <- дымовый тест веб-фронтенда (NEW)
│   └── web/
│       ├── index.html             <- главная страница GUI
│       ├── app.js                 <- логика GUI (все вызовы бэкенда)
│       ├── style.css              <- стили GUI (основная тема)
│       └── apple-design.css       <- стили GUI (Apple-подобная тема)
└── clew_tui/
    ├── README.md                  <- документация TUI (обновлена)
    ├── app.py                     <- точка входа TUI
    ├── bridge.py                  <- бридж TUI <-> backend
    ├── smoke_test.py              <- дымовый тест TUI (NEW)
    └── widgets/
        ├── __init__.py
        ├── status_bar.py          <- виджет строки статуса
        ├── chat_log.py            <- виджет лога чата
        ├── command_palette.py     <- виджет командной палитры (Ctrl+P)
        └── command_suggestions.py <- виджет подсказок команд
```

## Что было сделано

### GUI (clew/web/*)
1. **index.html** — исправлена структура DOM, добавлены недостающие узлы,
   которые требуются новому `app.js`. Удалены дублирующие ID, исправлены пути
   к стилям (`apple-design.css` теперь подгружается опционально).
2. **app.js** — приведён в соответствие с актуальным API `web_bridge.py`:
   - согласованы имена методов (camelCase на фронте <-> snake_case через бридж);
   - добавлены обработчики новых эндпоинтов бэкенда;
   - исправлены гонки в WebSocket-подписках;
   - добавлена защита от ошибок парсинга JSON-ответов.
3. **style.css / apple-design.css** — исправлены селекторы под новый DOM,
   убраны ссылки на несуществующие классы, исправлены overflow/scroll
   в логе чата.
4. **web_bridge.py** — приведены сигнатуры обработчиков в соответствие с
   вызовами фронта; добавлены недостающие обработчики, на которые ссылается
   новый `app.js`.
5. **web_smoke_test.py** — новый дымовый тест: проверяет, что `index.html`
   содержит все требуемые `app.js` хуки, что `web_bridge.py` экспортирует все
   эндпоинты, на которые ссылается фронт, и что CSS не ссылается на
   отсутствующие в DOM классы.

### TUI (clew_tui/*)
1. **app.py** — исправлены импорты виджетов, согласованы сигнатуры запуска с
   `bridge.py`, исправлено поведение при отсутствии файла сессии.
2. **bridge.py** — приведён в соответствие с актуальным backend API
   (`clew/agent_runtime.py`, `clew/web_bridge.py`), добавлены методы,
   которые использует новый `app.py`.
3. **widgets/status_bar.py** — исправлено отображение статуса квоты/модели,
   согласован формат сообщений с `bridge.py`.
4. **widgets/chat_log.py** — исправлены утечки при длинных сессиях,
   согласованы типы сообщений с `bridge.py`.
5. **widgets/command_palette.py** — исправлены хоткеи, добавлены команды,
   которые появились в новом `bridge.py`.
6. **widgets/command_suggestions.py** — исправлен список подсказок под
   актуальный набор команд.
7. **README.md** — обновлена документация TUI под новую раскладку виджетов.
8. **smoke_test.py** — новый дымовый тест: проверяет, что `app.py`
   импортируется без ошибок, что все виджеты экспортируют ожидаемые символы,
   и что `bridge.py` реализует все методы, на которые ссылается `app.py`.

## Smoke tests

Запуск:
```bash
python clew/web_smoke_test.py    # GUI
python clew_tui/smoke_test.py    # TUI
```

Оба теста проверяют целостность «фронтенд <-> бридж <-> backend» без
запуска реального LLM-провайдера.

## Соответствие бэкенду

Фронтенды (GUI и TUI) теперь покрывают **все** актуальные эндпоинты
`web_bridge.py` и `clew_tui/bridge.py`, включая:
- управление сессиями (new / switch / list / delete),
- отправку сообщений и стриминг ответа,
- approval-цикл для инструментов,
- команду `/skills`, `/agents`, `/context`, `/quota`,
- контекстные фрагменты и компактизацию,
- swarm-оркестрацию и субагентов,
- guardian-перехваты и approval-модалки.

## Установка

Распаковать архив поверх исходного дерева `clew/`:
```bash
unzip update_1.zip -d /path/to/clew/
```
Файлы встанут на свои места (пути совпадают с исходными).
