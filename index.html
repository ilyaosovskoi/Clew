The promise

A full agentic environment, not just a chat pane

No Python dependencies to install beyond the standard library. No telemetry. Absolute privacy for local models, with the flexibility to plug in cloud APIs. One agent runtime, four ways to reach it.

Privacy-first

Local models run 100% on-device. No telemetry, no tracking, no cloud unless you want it.

16 AI providers

Anthropic, OpenAI, Gemini, DeepSeek, Groq, xAI, z.ai, Mistral, Nvidia NIM, and more — or run Llama/Mistral/Qwen locally via Ollama or LM Studio. Plus 200+ via OpenRouter.

Four frontends, one runtime

Qt desktop GUI, Textual TUI, headless CLI, and an HTTP daemon with messenger control — all sharing the same agent underneath.

Features

Built around trust, not just speed

What matters when you're letting something else touch your code: what it plans, what it costs, who's watching, and how it fits the way you work.

Plans before it acts

Before editing a file, Clew lays out its plan in plain language, then checks off each step. You always know what's about to change.

Guardian safety review

Rule-based risk assessment, optionally backed by a live model review. Verdict: Assure, Modify, or Reject — runs the same whether you're watching or not.

Signed audit trail

Every tool call is Ed25519-signed and hash-chained to the one before it. Tampering, reordering, or deletion is detectable — keys never leave your machine.

Multi-provider consensus

Run the same task on 2–3 providers in parallel and see a structured diff of how their approaches diverge, before you commit to one.

Smart task-decomposition router

A cheap model splits your task into subtasks and routes each to whichever configured provider fits it best — by specialty and by cost. Add your API keys, pick auto, go.

MCP client & server

Connect any external MCP tool into the agent's catalog, or expose Clew itself as an MCP provider for other agents — read-only or write mode.

Web search & fetch

MCP-first search with ordered fallback, plus safe page fetching through a read-only researcher role that can never write, execute, or touch git.

Automatic learning loop

Detects rollbacks, force-pushes, and CI failures — and tasks that skipped self-verification — then writes a per-repo learning entry the agent reads next time.

Layered memory

A live task canvas tracks the current job's steps in a few hundred tokens. A cross-session persona profile remembers how you like to work, size-capped and editable.

autonomous

"Hermes" autonomous mode

Sandbox the agent to one workspace at the OS-kernel level, then control it entirely from Telegram — mandatory allow-list, a STOP kill switch, Guardian still runs.

Budget guardrails

Token usage and burn rate tracked live, per provider. Set hard cost caps, and cost-aware routing shifts to cheaper or local models under budget pressure.

Smart context

Git-aware filtering, relevance ranking, token budgeting, and live indexing — with tombstone compaction so old context shrinks without disappearing.

Get started

Three steps, no ceremony

No account, no cloud dashboard to configure first.

01

Install Clew

Download the native app for macOS, Windows, or Linux from the latest GitHub release. Requires Python 3.11+. Or pip install -e . from source.

02

Connect a model

Paste an API key for any supported cloud provider, or point Clew at a local Ollama or LM Studio server — auto-detected. Or just pick auto-router and let Clew handle it.

03

Describe the task

Open a project in the GUI (clew) or TUI (clew_tui) and tell Clew what you need. Review the plan, then let the agent read, write, and execute code.
